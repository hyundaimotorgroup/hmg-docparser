# 개인정보와 데이터 처리

> 원문: [privacy-and-data-handling.md](../privacy-and-data-handling.md).

HMG-Doc Parser는 로컬 CLI로 실행되지만 선택한 노드가 문서를 모델 서비스에
전송합니다. 레이아웃·OCR을 로컬에서 처리해도 이미지 입력을 지원하는 LLM/VLM
엔드포인트가 필요합니다. 사용 권한이 있는 문서·서비스를 선택하고 제공자의 보관,
학습 사용, 처리 지역, 보안, 비용 조건을 확인하세요. 외부 제공자의 요청 처리는
이 저장소가 통제하지 않습니다.

## 데이터 흐름

| 기능 | 처리 데이터 | 전달·보관 위치 |
| --- | --- | --- |
| PDF 파이프라인 | PDF·페이지 이미지·크롭·텍스트·표·프롬프트·생성 텍스트 | 로컬 처리와 YAML의 layout/OCR/LLM/VLM 엔드포인트. 페이지 전체·전역 문맥 노드는 요소별 노드보다 넓은 문맥을 전송할 수 있습니다. |
| 라우터 | 페이지·요소 이미지 업로드 | 설정한 라우터 서비스. 제공 로컬 진입점은 루프백으로 바인딩합니다. |
| 산출물 | 최종·중간 Markdown·이미지·표 영역·오류 | `output_dir`. [출력 경로](outputs-and-failures.md) 참고. |
| 모델 초기화 | 모델 파일·디코더 사전 | 외부 다운로드와 로컬 캐시. PDF 추론 데이터 전송과 구분합니다. |
| 설정 편집기 | 가져온 YAML·직접 입력한 자격 증명 | 브라우저 메모리·루프백 요청. 내보낸 YAML에 직접 값이 포함됩니다. |
| Langfuse | 모델·제공자·API 유형·토큰·작업/노드 메타데이터 | 선택적 `LANGFUSE_HOST` 전송. 제공 프로필 모두 비활성화. |
| Confluence | Markdown·로컬 첨부·제목·대상 ID | 별도로 선택한 HTTPS 대상. 원격 페이지·첨부를 변경할 수 있습니다. |

자격 증명은 비공개 환경변수나 `.env`에 보관하고 예제 YAML에는 환경변수 참조를
사용하세요. 키·내부 주소·직접 비밀값이 든 내보내기 파일·비공개 문서를 게시하지 마세요.
그룹/내부 프로필이 서비스 접근 권한을 부여하지는 않습니다.

Global Context가 있는 default·managed_endpoints·group_internal은
`skip_levels: [1]`로 일치하는 Stage 1 페이지를 추가 Global Context 후처리에
전송하지 않습니다. 라우터 업로드와 앞 단계의 경량 페이지 VLM 요청은 유지됩니다.
L2·레벨 미상은 기존 문맥을 전송하며 `[]`로 전체 대상 후처리를 복원합니다.
[설정 정책](configuration.md#단순-페이지의-global-context-호출-생략)을 참고하세요.

## 산출물과 보관

최종·중간 Markdown, `imgs/`, `table_imgs/`에는 원문 내용이 남을 수 있습니다.
`_page_split/`, `_layout_crops/`는 해당 노드의 `keep_page_artifacts: true`가 아니면
정리하지만 모든 출력·캐시·다운로드·복사본을 삭제하는 것은 아닙니다.

`save_debug_artifacts: true`는 디버그 Markdown을 저장할 수 있습니다. 구조화된 표
복구는 `_private/structured-recovery/`에 원본 표를 기록할 수 있습니다. `_private`는
이름 규칙이며 암호화나 접근 제어가 아닙니다. 출력·사용량 파일의 자동 보관 만료는
없으므로 파일시스템 권한, 백업 정책, 삭제 주기를 직접 적용하세요.

## 사용량·오류·텔레메트리

Dolphin 실패는 `_private/dolphin_failures/`에 원본 레이아웃 응답과 이미지 크기를
남길 수 있습니다. 문서 내용이 포함될 수 있으며 산출물 ZIP에서는 제외하지만
직접 삭제하기 전까지 로컬 파일로 남습니다.

`<output_dir>/_llm_usage.jsonl`에는 call/attempt/event·작업/노드/페이지 ID, 모델·제공자,
공급자 토큰·캐시 사용량과 선택적 비용 추정을 기록합니다. 누락 토큰은 null입니다. 해당 writer에는 프롬프트·모델 출력
텍스트가 포함되지 않지만 ID·파일명은 문서를 식별할 수 있습니다. 메모리의 사용량·진행
기록에는 프롬프트·출력이 포함될 수 있고 오류·디버그 산출물도 원문이나 제공자 정보를
노출할 수 있습니다. JSONL 형식만으로 모든 로그의 내용을 판단하지 마세요.

`langfuse.on: true`와 자격 증명을 설정하면 generation exporter가 일부 작업/노드·회계 메타데이터를 보냅니다.
모델명·숫자 usage·cost는 로컬 complete 비용에서만 보내며 가격 비활성화·부분 비용에서는 생략합니다. 이 payload에 프롬프트·출력·
문서 본문 필드를 넣지는 않습니다. 식별 가능한 메타데이터와 목적지를 검토하세요.
전송 실패는 파싱을 중단하지 않으므로 파싱 성공이 전달 성공의 증거는 아닙니다.
[Langfuse 안내](optional-capabilities.md#선택적-langfuse-사용량-내보내기)를 참고하세요.

## 편집기와 Confluence

편집기는 요청 메모리에서 그래프를 처리하고 애플리케이션 DB에 저장하지 않습니다.
브라우저 다운로드와 `pipeline.yaml`에는 직접 입력한 비밀값을 포함한 전체 설정이
남을 수 있습니다. 환경변수 참조를 권장하며 공유 전에 확인하세요. 탭을 닫아도
다운로드 파일은 삭제되지 않습니다.

Confluence는 별도 파이프라인입니다. 페이지 생성·갱신과 첨부 교체가 가능하고
`update_existing` 기본값은 `true`입니다. 실행 전 대상 공간, 계정, 쓰기 권한,
첨부 내용을 확인하세요. 결과 JSON에는 URL·제목·ID·오류가 포함될 수 있습니다.
원격 사본은 Confluence의 접근·보관 정책을 따릅니다.
[업로드 안내](optional-capabilities.md#선택적-confluence-업로드)를 참고하세요.

## 공유와 사고 신고

합성 또는 허가된 예제로 결과를 공유하세요. Markdown·이미지·표·디버그·복구·오류·
메타데이터를 함께 검토해야 하며 파일명 가리기만으로 내용이 제거되지는 않습니다.
[모델·데이터 자산](model-and-data-assets.md)과 [릴리스 점검표](release-checklist.md)를
참고하세요. 보안 문제는 [PSIRT](SECURITY.md)에 비공개로 신고합니다.

CLA 계정·전자 동의 기록은 조직이 수집 시 제공하는 개인정보 안내를 따릅니다.
이 파서 안내는 그 개인정보 안내를 대체하지 않습니다.

사용량 기록은 가격 기능과 독립적입니다. 선택한 가격 snapshot은 요율·식별 조건을 포함할 수 있으므로 비공개 실행 자료로 관리합니다. 가격 파일 자체는 ZIP·telemetry에 포함하지 않습니다. Langfuse의 모델명·숫자 usage·cost는 complete 비용에서만 전달하며 비활성화·부분 비용에서는 생략합니다. [가격 안내](llm-inference.md)를 참고하세요.
