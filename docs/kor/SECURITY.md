# 보안 정책

> 원문: [SECURITY.md](../../.github/SECURITY.md).

현대자동차그룹은 소프트웨어와 소스 저장소의 보안을 중요하게 다룹니다.

## 보안 취약점 신고
보안 취약점을 공개 GitHub Issue·Discussion·PR로 신고하지 말고
[psirt@hyundai.com](mailto:psirt@hyundai.com)으로 보내세요.

저장소 이름, 영향받는 버전·커밋, 환경, 재현 절차, 영향, 가능하면 최소 재현 예제를
포함하세요. 자격 증명과 비공개 문서 내용을 제거하고 민감한 증거 전달은 비공개
경로에서 조율하세요. 세부 내용을 공개하기 전에 조사와 대응 조율을 기다려 주세요.

## 범위와 배포 전제

이 저장소는 로컬 파서 CLI와 보조 서비스를 제공합니다. 공개 호스팅 파서 서비스가
아닙니다. Router·설정 편집기·Dolphin 1.5·Paddle 튜토리얼 실행 진입점은 루프백
바인딩으로 제한되며 다중 사용자 인증을 제공하지 않습니다. 외부 노출에는 별도로
검토한 배포 방식과 접근 제어가 필요합니다.

[HTTP 입력 한도](http-input-limits.md)는 요청 본문·디코딩 이미지·대기열·YAML 확장을
제한합니다. 추론 시간이나 전체 메모리를 보장하지는 않습니다. 파서 문서 한도는
[설정 안내](configuration.md)를 참고하세요.

신뢰하는 모델·pickle 파일만 사용하세요. 신뢰하지 않는 직렬화 파일을 로드하면 코드가
실행될 수 있습니다. `.env`, 내보낸 설정, 출력과 로그를 보호하세요. 제공자 호출은
문서를 설정된 엔드포인트로 전송할 수 있으며 Confluence는 원격 페이지·첨부를
변경할 수 있습니다. [데이터 처리](privacy-and-data-handling.md)와
[자산 조건](model-and-data-assets.md)을 확인하세요.

## 유지관리

현재 공개된 소스·의존성 파일을 사용하고 신고 시 커밋을 기록하세요. 버전별 보안
지원 일정이나 응답 시간 보장은 아직 공표되지 않았습니다. 의존성 검사와 릴리스
검증은 [릴리스 점검표](release-checklist.md)에서 관리합니다.
